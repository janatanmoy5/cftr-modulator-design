Fixed 2026-08-19 (6th pass, breaking issues found via real user run):
  1. pipeline.sh ordering bug: 02_extract_sequence_features.py required cf_mutations.csv,
     which was previously only created by 05_build_mutation_dataset.py -- but pipeline.sh
     runs 02 before 05. Fixed by moving the seed-mutation logic (SEED_MUTATIONS, KNOWN_LABELS,
     seeding function) into utils.py as ensure_mutations_seeded(), called by 02 on first run.
     05 now finds the file already seeded and proceeds straight to building the dataset --
     the full pipeline (01-06) now completes in ONE run from a clean checkout, verified.
  2. Stale config key crash: 02, 03, and 07 still referenced cfg["key_sites"]["ATP_site_NBD1"]
     and ["ATP_site_NBD2"], which were removed when ABP1/ABP2 were added. Added
     utils.atp_pocket_residues() to flatten the corrected ABP1/ABP2 structure into simple
     residue lists; all three scripts updated to use it. Renamed the derived feature columns
     accordingly: dist_to_nearest_ATP_site -> dist_to_nearest_ATP_pocket,
     in_NBD1_ATP_motif/in_NBD2_ATP_motif -> in_ABP1_degenerate_pocket/in_ABP2_hydrolytic_pocket
     (06 and 07 updated to match).
  3. AlphaFold model 404: hardcoded "_v4" URL broke when AlphaFold DB moved to v6.
     01_fetch_cftr_data.py now resolves the current model URL dynamically via the AlphaFold
     Prediction API (https://alphafold.ebi.ac.uk/api/prediction/P13569) and saves it locally
     under a version-independent filename (AF-P13569-F1-model_latest.{cif,pdb}); falls back to
     a guessed v6 URL if the API itself is unreachable. All downstream scripts (03, 11, 12, 13)
     updated to reference the fixed filename instead of a hardcoded version number.
  Full pipeline (01->07) re-validated end-to-end after all three fixes.
